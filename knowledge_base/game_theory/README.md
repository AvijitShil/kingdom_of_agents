# Domain: Strategic Interaction & Game Theory

The `game_theory/` domain provides the mathematical and strategic foundations for multi-agent interaction, equilibrium computation, worst-case adversarial defense, mechanism design, and cooperative coalition formation.

---

## Included Topics

1. **Nash Equilibrium** (`nash_equilibrium.md`):
   - Focus: Pure and mixed strategy equilibria, best-response dynamics, focal points (Schelling points), coordination dilemmas.
   - Primary Thinkers: John Nash, Thomas Schelling, John von Neumann.
2. **Minimax Strategy** (`minimax.md`):
   - Focus: Zero-sum games, worst-case payoff maximization, security levels, adversarial defense, minimax theorem.
   - Primary Thinkers: John von Neumann, Oskar Morgenstern, Abraham Wald.
3. **Evolutionary Game Theory** (`evolutionary_game_theory.md`):
   - Focus: Replicator dynamics, Evolutionarily Stable Strategies (ESS), Hawk-Dove games, Axelrod's Tit-for-Tat tournament.
   - Primary Thinkers: John Maynard Smith, George R. Price, Robert Axelrod.
4. **Pareto Optimality** (`pareto_optimality.md`):
   - Focus: Pareto frontiers, non-dominated resource allocations, Kaldor-Hicks efficiency, cooperative bargaining.
   - Primary Thinkers: Vilfredo Pareto, Kenneth Arrow, Nicholas Kaldor.
5. **Mechanism Design** (`mechanism_design.md`):
   - Focus: Reverse game theory, incentive compatibility, Vickrey-Clarke-Groves (VCG) mechanisms, adverse selection, moral hazard.
   - Primary Thinkers: Leonid Hurwicz, Eric Maskin, Roger Myerson, William Vickrey.
6. **Multi-Agent Coordination** (`multi_agent_coordination.md`):
   - Focus: Common-pool resource governance, Ostrom design principles, coalition formation, collective action dilemmas.
   - Primary Thinkers: Elinor Ostrom, Mancur Olson, Robert Aumann.
