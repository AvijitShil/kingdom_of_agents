# Domain: Psychology & Behavioral Economics

The `psychology/` domain investigates cognitive architectures, bounded rationality, psychological biases, motivational hierarchies, evolutionary behavioral adaptations, and reinforcement feedback loops. It provides autonomous agents with the tools to diagnose cognitive distortions, model peer vulnerabilities, navigate resource scarcity, and optimize internal decision heuristics.

---

## Included Topics

1. **Cognitive Biases** (`cognitive_biases.md`):
   - Focus: Systematic cognitive errors (confirmation bias, anchoring, loss aversion, sunk cost fallacy, availability heuristic) and formal algorithmic debiasing.
   - Primary Thinkers: Daniel Kahneman, Amos Tversky, Richard Thaler.
2. **Heuristic Decision Making** (`heuristic_decision_making.md`):
   - Focus: Bounded rationality, satisficing, fast-and-frugal heuristics, Dual-Process Theory (System 1 vs System 2), ecological rationality.
   - Primary Thinkers: Herbert Simon, Gerd Gigerenzer, Daniel Kahneman.
3. **Maslow's Hierarchy of Needs** (`maslow_hierarchy.md`):
   - Focus: Staged motivational priorities mapped to autonomous agent architectures (computational survival -> operational security -> clan belonging -> reputational esteem -> recursive self-actualization).
   - Primary Thinkers: Abraham Maslow, Carl Rogers, Douglas Kenrick.
4. **Evolutionary Psychology** (`evolutionary_psychology.md`):
   - Focus: Inclusive fitness, kin selection, reciprocal altruism, costly signaling theory, reputation tracking, cognitive cheater-detection modules.
   - Primary Thinkers: Leda Cosmides, John Tooby, Robert Trivers, W.D. Hamilton.
5. **Behavioral Reinforcement** (`behavioral_reinforcement.md`):
   - Focus: Operant conditioning, intermittent reinforcement schedules, reward shaping, temporal-difference learning, habituation loops.
   - Primary Thinkers: B.F. Skinner, Edward Thorndike, Richard Sutton, Andrew Barto.
